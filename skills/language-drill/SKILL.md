# Language Drill

Help a language structure become usable without laborious translation. The learner should spend most of the session producing language, with enough feedback to prevent repeated mistakes.

## Start with a workable exercise

Use the requested language, structure, or situation. In the original English-learning setting, English is a reasonable default when no target language is given; an explicitly requested language replaces it. Use the learner's familiar language for brief explanations when helpful.

If the learner does not know where to start, suggest one simple exercise and begin. Their first responses are enough to adjust difficulty; a complete level assessment or curriculum is unnecessary. For module-based selection or a progression map, read [the language map](references/language-map.md).

## Choose practice that serves the obstacle

- **Substitution drill:** give a base pattern and one cue, wait for the learner's sentence, respond briefly, and give the next cue. Change one dimension at first so the pattern remains visible.
- **Input before practice:** give a small set of varied examples when the learner cannot yet produce the structure, then let them try. A sentence list is input, not evidence of learned fluency.
- **Recall check:** supply cues without the model sentence. Use the learner's actual answers to decide whether to advance or return to supported practice.
- **Small role-play:** create a situation that needs the target structure; respond in character and save non-blocking feedback until a natural pause.

These are choices, not stages to complete in every session. Use one-at-a-time interaction for drills unless the learner asks for a batch worksheet.

## Feedback and progression

On an error, provide the corrected form and the smallest explanation needed, then give an opportunity to use it again. Continue when it works; if the same error persists, simplify the cue or contrast the confusing forms instead of accumulating more repetitions.

Vary the situation or reduce support when accurate production becomes consistent. Lower difficulty or shorten the set when the learner struggles or tires. There is no fixed repetition quota or universal pass threshold.

Do not claim to measure response speed when the interface does not expose it. Use accuracy, self-correction, dependence on prompts, and the learner's report of effort to judge readiness. Summarize a concrete improvement when useful, rather than praising every response.

Answer a requested “why” clearly, then offer a return to practice. An explicit request for explanation or a change of exercise is part of the session, not a failure of drilling.

Good work gives the learner repeated opportunities to produce the intended structure, catches consequential errors, and adjusts support from observed performance rather than an assumed level.
