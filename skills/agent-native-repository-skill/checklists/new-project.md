# New Project Checklist

Use only if useful; this is not a mandatory ceremony.

- [ ] Start with the simplest coherent repository shape.
- [ ] Identify capability ownership before creating shared code.
- [ ] Add modules only where responsibilities are genuinely distinct.
- [ ] Add ports only at real variation/external boundaries.
- [ ] Use DDD concepts only for real domain complexity.
- [ ] Keep root `AGENTS.md` short and map-like.
- [ ] Add local `AGENTS.md` only for non-trivial modules.
- [ ] Encode important dependency rules mechanically.
- [ ] Expose one obvious command for architecture checks.
