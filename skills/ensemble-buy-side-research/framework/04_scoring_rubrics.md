# Scoring Rubrics

Scores are not a substitute for judgment. They are forcing functions.

Use 1–5 unless specified.

```text
1 = weak
2 = below average
3 = mixed / acceptable
4 = strong
5 = exceptional
```

## Problem Quality Score

| Factor | 1 | 3 | 5 |
|---|---:|---:|---:|
| Urgency | nice-to-have | useful | mission-critical |
| Recurrence | one-off | periodic | continuous |
| Budget Owner | unclear | partially clear | clear buyer with budget |
| Measurability | vague | partially measurable | directly measurable |
| Switching Incentive | weak | moderate | strong economic reason |

Interpretation:

```text
0–10: weak problem
11–17: real but may be niche
18–25: high-quality problem
```

## Profit Pool Score

| Factor | 1 | 3 | 5 |
|---|---:|---:|---:|
| Gross Margin Potential | commodity | normal | structurally high |
| Pricing Power | price taker | mixed | price setter |
| Switching Cost | low | moderate | high |
| Supply Scarcity | abundant | balanced | constrained |
| IP / Know-how Barrier | low | moderate | high |
| Customer Concentration Risk | severe | manageable | diversified |
| Capex Burden | heavy with weak return | manageable | high return on capital |
| Operating Leverage | low | mixed | high |
| Cycle Risk | high | moderate | low |
| Regulatory / License Barrier | none | some | meaningful protection |

Interpretation:

```text
10–24: poor profit pool
25–36: mixed
37–44: attractive
45–50: exceptional, verify crowding
```

## Commoditization Risk Score

Higher means worse.

| Factor | 1 | 3 | 5 |
|---|---:|---:|---:|
| Standardization | customized | semi-standard | fully standardized |
| Supplier Count | few | several | many |
| Customer Self-build | unlikely | possible | likely |
| Open-source / Substitute Risk | low | moderate | high |
| Switching Cost | high | moderate | low |
| Capacity Additions | constrained | normal | aggressive |
| ASP Pressure | low | moderate | high |
| Differentiation | strong | mixed | weak |

Interpretation:

```text
8–16: low commoditization risk
17–27: moderate
28–40: high, avoid unless timing or valuation is exceptional
```

## Investability Score

Use this as a final check, not a mechanical decision.

| Factor | Weight |
|---|---:|
| Problem Quality | 20% |
| Profit Pool Quality | 25% |
| Consensus Gap | 20% |
| Data Availability | 15% |
| Timing / Catalyst | 10% |
| Valuation Sanity | 10% |

Decision guide:

```text
< 50: Discard
50–65: Watch
66–80: Deep Dive
> 80: Potential Investment Thesis
```

## Consensus Gap Score

| Factor | 1 | 3 | 5 |
|---|---:|---:|---:|
| Market Narrative Clarity | unclear | known | very clear |
| Evidence of Crowding | none | some | strong |
| Misunderstood Variable | none | possible | clear |
| Timing Mismatch | none | possible | meaningful |
| Layer Mispricing | none | possible | clear |

Interpretation:

```text
Low score does not mean bad company; it means weak variant perception.
```

## Evidence Quality Score

| Source Type | Default Score |
|---|---:|
| Primary filing / annual report / 10-K / 10-Q | 5 |
| Company earnings call transcript | 5 |
| Regulator / government statistical source | 5 |
| Exchange announcement | 5 |
| Company investor presentation | 4 |
| Reputable financial media | 4 |
| Industry association | 3–4 |
| Sell-side report | 3 |
| Expert interview | 3–4 |
| Social media / forum | 1–2 |
| Unsourced claim | 0 |

## Thesis Readiness Checklist

Do not label as `Potential Investment Thesis` unless all are true:

```text
[ ] Problem is specific and economic.
[ ] Value-chain layer is identified.
[ ] Profit pool is credible.
[ ] Consensus is stated.
[ ] Variant view is testable.
[ ] Key variables are observable.
[ ] Falsification conditions are explicit.
[ ] Next research action is concrete.
```
