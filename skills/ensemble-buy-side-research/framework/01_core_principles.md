# Core Principles

## 1. Start With the Problem, Not the Theme

A theme is not investable by itself.

Weak:

```text
Humanoid robots are a major future trend.
```

Strong:

```text
Humanoid robots attempt to solve labor scarcity and automation flexibility in environments where fixed industrial automation is too rigid.
```

Every direction must be translated into:

```text
What is broken?
Who pays to fix it?
Why now?
What variable improves if it works?
```

## 2. A Direction Is a Value Chain, Not a Stock List

A market direction usually contains several layers:

```text
upstream inputs
core components
systems integration
software / control layer
distribution
customer application
aftermarket / services
```

The first obvious beneficiary is not always the best profit pool.

## 3. Profit Pool Comes Before Popularity

High attention does not imply high economics. The best profit pool is usually where at least one of the following exists:

```text
scarcity
technical bottleneck
process know-how
regulatory license
customer lock-in
switching cost
data advantage
scale advantage
ecosystem control
```

## 4. Consensus Must Be Explicit

Never write a thesis without stating what the market likely already believes.

A thesis only matters if it answers:

```text
What is already priced?
What is not priced?
What is priced incorrectly?
```

## 5. Variant View Must Be Measurable

A variant perception is not a personality trait. It must map to:

```text
observable data
a value-chain layer
a time horizon
an error condition
```

## 6. Good Research Ends With a Watchlist

The output should produce a monitoring system, not just a memo.

A watchlist converts qualitative judgment into repeatable tracking:

```text
If variable X moves above/below threshold Y, update thesis status.
```

## 7. Falsification Protects Against Narrative Addiction

For every thesis, ask:

```text
What evidence would make me downgrade this idea?
What evidence would make me abandon it?
What evidence would show the market was right and I was wrong?
```

## 8. Do Not Confuse First-order and Second-order Effects

A first-order beneficiary may see immediate revenue impact. A second-order beneficiary may gain pricing power, better mix, or lower cost later.

Example structure:

```text
First-order: direct supplier to the demand shock.
Second-order: bottleneck provider, equipment vendor, infrastructure enabler, or replacement cycle beneficiary.
```

## 9. Time Horizon Matters

Separate:

```text
1–3 months: narrative and positioning
3–12 months: order, pricing, margin evidence
1–3 years: capacity, share shift, structural profitability
```

## 10. The Best Output Is Decision-Oriented

Every memo should help decide:

```text
Ignore
Watch
Deep dive
Build position candidate
```
