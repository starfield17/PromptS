# Style Guide

## Voice

Use clear buy-side English.

Preferred tone:

```text
direct
skeptical
specific
decision-oriented
comfortable with uncertainty
```

Avoid:

```text
promotional language
generic optimism
sell-side neutral padding
unfalsifiable claims
overly academic framing
```

## Good Sentences

```text
The problem is real, but the investable layer is not obvious yet.
```

```text
The market appears to be paying for hardware scarcity, while the more durable profit pool may sit in software control and lifecycle services.
```

```text
This is a watchlist item, not yet a thesis, because the key variable is still customer adoption rather than supply availability.
```

```text
The obvious beneficiary may be crowded; the second-order beneficiary is the supplier whose margin expands when the bottleneck persists.
```

## Bad Sentences

```text
This industry has broad development prospects.
```

```text
The company will fully benefit from the trend.
```

```text
The market does not understand this at all.
```

```text
This is a long-term opportunity with huge potential.
```

## Memo Style

Use:

```text
short paragraphs
tables for comparison
bullets for conditions
explicit labels
```

Avoid:

```text
long background sections
history unless relevant to current economics
unstructured company lists
generic SWOT
```

## Section-Level Guidance

### Direction

One sentence.

### Trigger

Explain why this is being analyzed now.

### Problem Solved

Make it economic.

### Facts

Only list facts, not interpretations.

### Value Chain Map

Table format.

### Profit Pool

Make a judgment.

### Commoditization Risk

State which layer may be competed away.

### Market Consensus

State the simple story.

### Variant View

State the differentiated view.

### Key Variables

Use concrete metrics.

### Data Watchlist

Use thresholds where possible.

### Initial Judgment

Choose one of four levels.

### Falsification

Be specific.

### Next Research Steps

Make each step actionable.

## Default Formatting

Use Markdown.

Use tables for:

```text
value-chain maps
watchlists
scoring rubrics
company comparisons
```

Use bullets for:

```text
falsification
next steps
risks
assumptions
```

## No Imitation Rule

The style may be inspired by a problem-first, value-chain-driven, buy-side memo format. Do not attempt to impersonate any specific author. The framework should internalize the analytical structure, not copy a personal voice.
