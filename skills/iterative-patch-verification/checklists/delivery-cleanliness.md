# Delivery Cleanliness Checklist

- [ ] All intended source changes are committed.
- [ ] All regression tests are committed.
- [ ] The final working tree is clean.
- [ ] `git diff --check` is clean.
- [ ] Temporary review tests are removed unless intentionally retained.
- [ ] Test run directories and logs are removed.
- [ ] Generated summaries are not accidentally committed.
- [ ] Prebuilt binaries are removed unless intentionally shipped.
- [ ] Shipped binaries match the current commit and are executable.
- [ ] The package contains the claimed commit.
- [ ] Build instructions are documented.
- [ ] No secret, credential, machine-specific path, or local cache is included.
